# 网页小游戏交付模板

## 触发条件

- 用户要求“做一个网页小游戏 / HTML 小游戏 / 贪吃蛇 / 打砖块 / 记忆翻牌”等
- 用户要求把玩法做成可双击打开的本地页面

## 交付步骤

1. **确认需求三要素**：玩法（规则/胜负）、操作方式（键盘/鼠标/触屏）、视觉风格（一句话即可），缺失时先反问，不自行脑补
2. **单文件实现**：交付一个 `index.html`，内联 CSS 与 JS，双击即可在浏览器打开
3. **核心机制齐备**：
   - 开始/重开入口（按钮或空格键）
   - 计分与最高分（`localStorage` 存最高分）
   - 明确的结束条件（胜利/失败/超时）与结算提示
   - 键盘操作绑定 `keydown`，并同步提供鼠标/触屏可点按钮（移动端可用）
4. **中文界面**：标题、按钮、提示语全部中文，不用英文占位
5. **验证（必须执行）**：
   - 用 `node --check` 或浏览器控制台语法检查 JS（`codebox` 跑一段静态检查）
   - 文件保存后 `read` 回来核对关键函数/事件绑定存在
   - 交付前说明“双击 index.html 即可运行”，并给出修改入口（文件路径）

## 交付清单（最终回复必含）

- 文件保存路径（完整绝对路径）
- 玩法与操作说明（两三句）
- 验证方式（已做什么检查、结果）
- 本次改进点：一行说明下次同类任务可以更快/更稳的地方

## 常见坑

- 忘记 `keydown` 阻止默认滚动（空格/方向键页面跳动）
- 高分存储不兼容（`localStorage` 在 `file://` 下正常，无需网络）
- 动画用 `requestAnimationFrame` 而非 `setInterval`，避免卡顿
- 外链 CDN（字体/库）会导致离线打不开——一律内联
