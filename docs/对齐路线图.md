## 🎯 终态目标：1:1 移植（仅品牌不同）

> 指令：界面、交互、功能与参考实现完全相同，仅品牌不同。这是分阶段工程，路径如下。

### 技术路径评估
参考实现桌面端 = assistant-ui 框架 + Tailwind 4 设计令牌 + nanostores + 网关 RPC；黄泉 = 自研 zustand + IPC 引擎。两条路线：
- **路线 A（渐进移植，当前执行）**：逐组件按参考实现 1:1 重写到现有架构（本轮已完成：脚手架体系/聚合运行/滚动 ticker/粘性气泡/时间线/查找/执行组）。优点：功能零回退、随时可发布；缺点：像素级细节需逐个追。
- **路线 B（整体换壳）**：直接采用参考实现桌面端 UI 代码，引擎桥接为 RPC 适配层。像素 100% 一致，但需要：引入 Tailwind 4 + assistant-ui + nanostores、实现网关 RPC 面（sessions/approvals/threads…）、功能全量重测——周级工程，期间主版本冻结。

### 已执行的精确对齐（路线 A）
视觉令牌：正文 0.8125rem / 工具 0.6875rem / 行盒 1.125rem / 脚手架灰 64% / 淡化 0.67 / 悬停 120ms；
悬停药丸（贴文字宽度的背景+外扩 3px）、caret 右缘静息可见度、操作条静息 50%、节奏（轮 6px/块 12px/脚手架 4px/段 11px）、composer 玻璃（blur 12px + 饱和 1.12）。

### 路线 B 启动条件
功能集与参考实现等价（阶段一、二完成后）→ 评估以参考实现 UI 壳 + 黄泉引擎桥接整体替换渲染层，一次性达成像素级一致。
