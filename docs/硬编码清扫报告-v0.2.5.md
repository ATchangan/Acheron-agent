## 四、规则落地(防回潮)

- global.css 的 `:root` 与 `[data-theme]` 块是唯一允许裸 hex 的地方
- `rgba(var(--skin-accent),x)` 引用收敛为 `--skin-accent-soft/mid/strong/bright`
- 新增语义 token: `--danger/--success/--warning` + `--danger-soft/--success-soft/--warning-soft` + `--on-accent/--overlay/--overlay-strong`
- 校验脚本 `scripts/check-theme-tokens.mjs` 纳入 token 完整性检查

## 五、结论

- 状态色/皮肤色/遮罩类裸色已清零(token 化)
- 剩余均为**有明确语义的设计数据**(分类色/色点)或**历史面板副本**(报告如上)
- 严格「组件零裸色」未 100% 达成,已逐类确认与报告,不隐瞒
