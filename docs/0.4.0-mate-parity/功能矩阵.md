## 明确跳过

| 功能 | 原因 |
| --- | --- |
| Steam Workshop / Steam DLC | MatePro 禁上 Steam；且黄泉桌宠不开 Steam 渠道 |
| Minecraft Integration | 受众极小，非目标场景 |
| 游戏反作弊注入兼容 | 无游戏注入需求 |
| Debugging Menu | 内部开发用，不进入用户界面 |
