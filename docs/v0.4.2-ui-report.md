## 二、功能落点

1. 标题栏与会话标题解耦：ChatView 不再渲染头部，标题/模式徽标常驻外壳标题栏。
2. 会话按 `updatedAt` 本地日期分组（置顶 / 今天 / 昨天 / 更早），分区可折叠；行内悬停显示置顶/删除。
3. 「文件」导航改为打开右栏文件面板，不再独占整页视图。
4. 状态行模板（`${model}/${workDir}/${context}/${tokens}/${agents}`）迁移到状态栏左簇，功能保留。
5. Ctrl+N 新对话、Ctrl+K 命令面板全局快捷键。
6. 会话输出重排：时间线时间戳（HH:MM，同分钟去重）、思考过程状态机（思考中+计时 → 思考了 Xs / 快速思考 / 思考）、回合时长徽标、流式停滞提示（2s 无输出计时）、助手操作栏底部右对齐悬停浮现、回合内助手块 0.75rem 间距。
7. 设置页重排：OverlayView 去标题栏（浅色遮罩 + blur + rounded-xl 卡片 + 拖拽条 + 悬浮关闭）；设置左导航按「模型服务 / 外观 / 数据任务 / 系统」分组，28px 行高、图标+标签、激活态描边底；导入/导出/重置收到底部；右主内容限宽居中。
8. 编队管理重构为子代理活动面板：删除 7 角色配置页，默认单 Agent 直接执行；dispatch 分派时按行展示子代理（状态图标/目标/角色·耗时·步数·更新，可展开计划步骤流）；角色启用/并发等配置保留在 设置 → 协作。
9. 版块补齐：技能/产物提为工作区页面；定时任务/命令中心/配置档案提为 Overlay；会话支持无损归档/恢复与归档筛选、按更新时间/Token 排序；Composer 加建议 pills 与 模型 pill 菜单（移除单 Agent 角色下拉）；消息加文字标签回应与链接预览卡；状态栏右键自定义显示项。
10. 继续补齐：API Keys 管理页（脱敏/显示/复制/删除/新增）；可重绑快捷键（默认 Ctrl+K/N/B/J/,，设置页录制与恢复）；右栏终端（工作目录执行）与评审面板；任务完成/失败桌面通知接线（受桌面通知开关控制）。
11. 语言收敛为仅简体中文：设置 → 角色 移除多语言下拉（强制简体中文回复），打包 electronLanguages 仅保留 zh-CN。
12. 渲染补齐：代码块接入 rehype-highlight 语法高亮（github-dark，深浅主题适配）；主题画廊新增 6 套预设（深蓝/墨绿/琥珀/粉彩/石墨/极光），主题 token 校验 12 套全过。
13. 分栏多会话（多区布局的本地简化版）：标题栏分栏工具 + 会话选择菜单，右侧只读窗格直接从磁盘加载消息渲染（回合/气泡/Markdown 高亮/思考/工具行），可关闭。
14. 配色重构：深色 = 深蓝底（chrome #0D2667 / sidebar #09286F / card #142345 / elevated #14254F）+ 奶油暖字（#FFE6CB 三级透明度）+ 蓝强调（#0053FD，悬停/选中/气泡蓝染）；浅色 = 冷白底（#F8FAFF/#F3F7FF）+ 蓝强调（#0053FD）+ 深灰字（#17171A）；语义色统一深色覆盖（danger #E75E78 / success #55A583 / purple #9E94D5）；边框取蓝调（#3158AD 系）；按钮白字全部改主题反色（--on-accent），默认主题 violet/dark/black 统一为深色。
15. 界面修复：补定义缺失的 --bg-hover-strong；侧栏页面导航（技能/产物等）按钮重置 UA 默认灰底白边，改为扁平导航行（透明底、悬停蓝染、激活低透明度蓝底奶油字）。
16. 主题体系：内置 ocean/midnight/ember/mono/cyberpunk/slate 六套预设（色值逐项映射到 19 项 token），默认主题 = 极黑；外观页仅展示内置预设 + 浅色 + 自定义；品牌 logo 为白色瓷片 + 深色字标，深浅主题一致。
